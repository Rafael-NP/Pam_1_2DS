## Proposta de atividade:

### Dinâmica — “Quem sou eu? Tecnologia Edition”

Como funciona:

Escolhemos alguns voluntários da sala.
Cada voluntário recebe um papel com uma tecnologia ou conceito, sem poder ver o que está escrito.
Ele pode fazer perguntas para a sala, mas só pode receber respostas de “sim” ou “não”.
O objetivo é descobrir o que está escrito no papel.
Quem descobrir primeiro ganha um ponto.
O que pode aparecer nos papéis:
